AIMemo 설치 방법
만든 날짜: 2026-11-17 13:37   버전: v1.6.1

1. AIMemo.exe 를 내려받아 원하는 폴더에 둡니다.
   (예: 내 문서\AIMemo  또는  C:\AIMemo)
   * 따로 설치할 것은 없습니다. 이 파일 하나면 됩니다.
   * C:\Program Files 처럼 관리자만 쓸 수 있는 폴더에 두면
     자동 업데이트가 파일을 바꾸지 못하고 알리기만 합니다.

2. 더블클릭해서 실행합니다.
   윈도우가 "PC를 보호했습니다"라고 하면
   [추가 정보] -> [실행]을 누르면 됩니다.
   (직접 만든 프로그램이라 서명이 없어서 나오는 안내입니다)

   처음 실행하면 "윈도우를 켤 때 AIMemo도 자동으로 실행할까요?" 를 묻습니다.
   [예]를 누르면 시작프로그램에 추가되어 컴퓨터를 켜면 메모가 바로 뜹니다.
   나중에 트레이 아이콘 우클릭 -> 환경 설정 -> 'Windows 시작 시 자동 실행' 에서
   언제든 켜거나 끌 수 있습니다.

3. 트레이(시계 옆) 아이콘 우클릭 -> 환경 설정 에서
   - 구글드라이브 연결: 쓰던 PC와 같은 클라이언트 ID/시크릿을 넣고 같은 구글 계정으로 연결
   - AI: 쓰던 API 키 입력

4. 연결하면 메모가 드라이브에서 내려옵니다.

5. 새 버전이 나오면 AIMemo가 알아서 받아 검증해 두고
   트레이 알림으로 "지금 다시 시작할까요?" 를 묻습니다.
   미루면 다음에 켤 때 바뀝니다. 메모는 그대로입니다.
   (받는 곳: https://github.com/medigi84-maker/AIMemo-release)

자주 쓰는 단축키
   Ctrl+Alt+N   새 메모
   Ctrl+Alt+P   화면 영역 캡처 -> 메모
   Ctrl+Alt+F   메모 찾기
   PageUp       모든 메모 맨 위로
   PageDown     모든 메모 바탕화면으로

메모가 저장되는 곳: %APPDATA%\AIMemo
