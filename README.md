# AIMemo 설치 파일

바탕화면 포스트잇 메모 프로그램 AIMemo 의 배포용 저장소입니다. 소스는 따로 비공개로 관리합니다.

- 받기: [AIMemo.zip](https://github.com/medigi84-maker/AIMemo-release/raw/main/AIMemo.zip) - 압축을 풀어 AIMemo.exe 를 원하는 폴더(예: 내 문서\AIMemo)에 두고 실행
- 설치 방법: 설치 방법.txt
- 처음 실행하면 윈도우 시작프로그램에 넣을지 묻습니다. 트레이 아이콘 우클릭 -> 환경 설정 -> 'Windows 시작 시 자동 실행' 에서 언제든 켜고 끌 수 있습니다.
- 한 번 설치하면 새 버전이 나올 때 AIMemo 가 알아서 받아 검증한 뒤, 다시 시작할지 트레이 알림으로 묻습니다.
- version.txt: 버전과 AIMemo.exe 의 SHA-256 지문(받은 파일이 온전한지 맞춰 보는 데 씀)
